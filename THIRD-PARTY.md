# Third-party software policy

MechOS scripts can install or integrate third-party software, but this alpha ZIP does not contain Steam binaries, NVIDIA proprietary drivers, Unity Editors, Unreal Engine, or VRChat Creator Companion.

The installer obtains Fedora/RPM Fusion packages from their repositories at install time. Unity Hub is obtained from Unity's RPM repository when the creator setup helper is used. Unreal Engine remains a user-authorized install from Epic. This keeps the MechOS project separable from third-party redistribution rights and licenses.

The included visual assets are original MechOS concept artwork generated for this project. They are mech-combat inspired rather than copies of game assets.
