# Third-party software policy

MechOS scripts install or integrate third-party software from authorized sources. The repository does not contain Steam binaries, proprietary NVIDIA packages, Unity Editors, Unreal Engine, paid assets or VRChat Creator Companion.

- Arch packages are downloaded from configured Arch Linux repositories during the build or installation.
- Flatpak applications are downloaded from the configured Flathub remote when the user selects them.
- Unity Hub may be installed through its available Flatpak distribution; Unity Editor versions remain user-selected.
- Unreal Engine uses Epic's authorized Linux source or distribution workflow.
- VRChat Creator Companion is Windows-only and is not represented as a native Linux application.
- Steam, game stores and launchers remain governed by their own accounts, licenses and platform support.

The included MechOS visual assets are project branding. No anti-cheat bypass or proprietary game asset redistribution is included.
